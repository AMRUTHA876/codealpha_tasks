# E-Commerce Sales Exploratory Data Analysis

## CodeAlpha Data Analytics Internship – Task 2

This project performs Exploratory Data Analysis (EDA) on an E-Commerce Sales dataset to identify important sales trends, product performance, regional patterns, profitability, and relationships between business variables.

## Objectives

- Understand the dataset structure and variables
- Clean and prepare the data
- Analyze sales and profit trends
- Identify top-performing products and categories
- Analyze regional performance
- Study discount, sales, and profit relationships
- Generate meaningful business insights

## Analysis Performed

- Data Understanding
- Data Cleaning
- Missing Value Analysis
- Duplicate Analysis
- Descriptive Statistics
- Sales Analysis
- Product and Category Analysis
- Regional Analysis
- Profitability Analysis
- Correlation Analysis
- Data Visualization

## Visualizations

The project includes charts for:

- Sales trends
- Sales by category
- Profit by category
- Regional performance
- Top products
- Discount vs Profit
- Sales vs Profit
- Correlation analysis

## How to Run

Install the required packages:

    pip install -r requirements.txt

Run the Streamlit dashboard:

    streamlit run app.py

## Conclusion

This project demonstrates how Exploratory Data Analysis and data visualization can be used to understand E-Commerce sales data and generate useful business insights.
